# React Welcome

A minimal React app (Vite) with a `Welcome` component.

## Install

```bash
cd react-welcome
npm install
```

## Run (dev)

```bash
npm run dev
```

Open the printed `localhost` URL in your browser.

## What was added

- `src/components/Welcome.jsx` — component that accepts a `name` prop and displays `Welcome, [name]!`. If `name` is not passed, it shows `Welcome, Guest!`.
- Example usage in `src/App.jsx` showing both with and without `name`.
